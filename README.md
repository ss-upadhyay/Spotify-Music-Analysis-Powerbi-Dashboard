# Spotify Music Analysis Dashboard

This project presents an interactive Power BI dashboard analysing Spotify music data to uncover insights into songs, artists, streams, playlists, and musical characteristics.

## Dashboard Insights

- Overall music dataset analysis with **943 songs** and **645 artists**
- Top Spotify, Deezer, and Apple playlists by track performance
- Top 10 artists based on total streams
- Major vs Minor song distribution
- Track-level stream performance analysis
- Audio feature analysis including Energy, Danceability, Valence, Liveness, and Acousticness
- BPM and release-date trend analysis
- Interactive filters for Artist, Release Year, BPM, Key, and Artist Count

## Key Insight

The analysis shows that streaming performance is highly concentrated among a small group of popular artists and tracks.

Tracks such as **Blinding Lights by The Weeknd** demonstrate exceptionally high streaming numbers, while playlist performance varies across Spotify, Deezer, and Apple.

The dashboard also allows users to explore how musical characteristics such as **Energy, Danceability, and Valence** relate to individual tracks and their overall performance.
